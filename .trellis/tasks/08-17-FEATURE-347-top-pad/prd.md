# FEATURE-347 搜索框顶距对齐底距

## 目标

底部悬浮面板里，搜索框到窗口上沿的留白与底栏到窗口下沿的留白一致。

## 背景 / 已知事实

- 用户要求「输入框和顶部距离留白参考底部」。
- `bottomFloatingLayout` 外壳现为 `.padding(.top, 2)` + `.padding(.bottom, 8)`。
- `searchBar` 在底部样式下还有 `.padding(.top, 2)`，合计顶距约 4pt，底距 8pt，上下不对称。
- 底栏本身用 `fixedSize(vertical: true)`，不再额外加顶/底垫。

## 需求要点

- 外壳上下内边距都用 8pt。
- 搜索框自身不再额外加顶垫。
- 经典面板搜索栏内边距不动。

## 范围外

- 不改左右留白、卡片轨道、快捷键。
- 不推上游。

## 验收标准

- [ ] 底部悬浮打开后，搜索框到上沿与底栏到下沿视觉间距一致（均为 8pt 外壳垫）。
- [ ] `swift build` 通过并重装本机应用。
