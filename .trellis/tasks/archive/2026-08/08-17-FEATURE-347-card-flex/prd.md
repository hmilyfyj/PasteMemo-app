# FEATURE-347 拉高悬浮框时卡片区自适应

## 目标

用户垂直拉高底部悬浮面板时，底栏（粘贴目标 + 快捷键提示那一行）高度保持不变，卡片轨道吃掉多出来的高度并跟着变高。

## 背景 / 已知事实

- 用户截图（comment `b71d430a`）显示拉高后卡片下方、底栏再下方出现大块空白。
- `QuickPanelView.bottomCardMetrics` 把 `railHeight` 算成 `min(size.height * 0.58, 240)`，卡片最高 240pt。
- `bottomFloatingLayout` 的 VStack 是 `alignment: .top`，卡片定高后剩余空间全部落在底栏下面。
- 底栏是 `footerBar`（`PasteMemo` /「粘贴到 X」+ 快捷键），用户说的「底部一行」就是它。

## 需求要点

- 搜索框、分类条、底栏用固有高度，不随窗口变高。
- 卡片轨道 `maxHeight: .infinity`，卡片高度按轨道实际高度计算。
- 去掉 240 的卡片高度上限。
- 展开预览（`⌘O`）时预览区吃剩余空间，卡片轨道保持一排合理高度。

## 范围外

- 不改经典面板布局。
- 不推代码给上游。

## 验收标准

- [x] 拉高面板时底栏高度不变，空白出现在卡片区域而不是底栏下方。
- [x] 卡片随轨道变高，内容仍完整可见。
- [x] 压矮到最小高度时底栏仍在，卡片不低于可用下限。
- [x] `swift build` 通过并重装 `/Applications/PasteMemo.app`。
