# 区分悬浮框类型与分组标签

## Goal

在悬浮框首个分组前加入留白与竖向分隔线，并更新本机 ARM 应用与现有 PR。

## Requirements

- 悬浮框中类型和分组之间有明显间隔，避免混淆两类标签。
- 只在首个分组之前存在其他标签时显示一次竖向分隔线，两侧留白。
- 分隔线不参与点击、键盘切换或无障碍导航，沿用现有分组筛选。

## Acceptance Criteria

- [x] 悬浮框类型和分组之间显示分隔线，两侧增加留白。
- [x] 无分组或分组是首个标签时不显示多余分隔线；经典样式保持原样。
- [x] make test（448 tests）、make check 通过，稳定 ARM 应用更新启动。
- [ ] 现有 PR #27 更新。

## Notes

- 轻量 UI 调整，仅修改 QuickPanelView 的悬浮标签渲染，沿用现有分组数据和筛选顺序。
