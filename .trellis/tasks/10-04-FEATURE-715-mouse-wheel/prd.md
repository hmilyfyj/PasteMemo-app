# FEATURE-715 悬浮卡片滚轮横向滚动

## Goal

鼠标在悬浮卡片区竖向滚轮可横向滚动，保留触控板手势和其他区域原生滚动。

## Requirements

- 鼠标停在悬浮卡片区时，竖向滚轮向下/向上分别驱动横向向右/向左滚动。
- 触控板横向/斜向滚动和已有横向滚轮事件仍走原生路径；支持 Mos 平滑后的精确竖向滚动。
- 搜索栏、分类、预览区、弹出菜单和其他窗口不受影响。

## Acceptance Criteria

- [x] 滚动距离单位、方向、边界及原生横向手势有回归验证。
- [x] 真实 SwiftUI 卡片内容挂载能定位正确的原生滚动容器并横向移动。
- [x] make test（448 项）、make check、ARM 签名安装通过。
- 交付到原 PR #25，源分支 agent/agent/929e38175114，目标 main。

## Notes

- 修改边界：卡片区添加 AppKit 滚轮桥接，作用范围限定当前卡片滚动容器；不修改主干已有布局。
- 普通滚轮使用原生 horizontalLineScroll 换算距离，精确滚动使用像素距离，通过原生 NSClipView 滚动和约束边界。
- 使用透明 background 标记及局部事件监听，不接管点击、右键、拖拽或键盘。
